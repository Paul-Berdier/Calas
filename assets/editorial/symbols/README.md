# Illustrations fournies par Sara

Ces huit PNG de 900 × 520 pixels sont extraits directement du document « Symboles et images — site Calas Conseil », transmis par Paul le 1er novembre 2026. Le document autorise leur reprise comme illustrations. Aucune photo de personne, de cliente ou de participante n'a été créée ou substituée.

Les originaux restent inchangés. Les versions servies sont des WebP optimisés sous `apps/web/public/images/symbols/`. Régénération volontaire : `node scripts/editorial-assets.mjs`. Cette commande n'importe aucun contenu dans le CMS et ne publie rien.

Les illustrations sont décoratives, avec une alternative vide : leur sens est exprimé dans le texte voisin. L'administration propose des remplacements via la médiathèque dans **Accueil → Images de l'accueil** ; les photographies ajoutées conservent leur texte alternatif. Les portraits se règlent dans les fiches des deux personnes. La photo finale reste facultative, en attente d'une photo authentique autorisée.

Ces illustrations ne remplacent pas la source unique du logo : `assets/brand/geometry.mjs` reste inchangé.
